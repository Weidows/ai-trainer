# 人工智能训练师（三级）备考工作台

上海交通大学《人工智能训练师（三级）》社会化职业技能等级认定的本地备考站点：考纲概览、900 道理论题库、40 道实操题、速查表、按真实卷面组卷的模拟考。

纯前端，`npm run dev` 就能用，**不需要 Python 环境**，所有作答记录存在浏览器 localStorage。

## 四个页面

| 页面 | 内容 |
| --- | --- |
| 概览 | 卷面结构（理论 190 题 / 实操 6 题）、认定与竞赛两套计分、10 个理论单元题量分布、9 单元 308 个细目点的考纲树、难度判断、四周备考路线、覆盖度说明 |
| 刷题 | 理论 900 题（按题型 / 单元 / 未做 / 错题筛选，可一键混排打散顺序，答题即时判对错 + 解析，可复制题目去问别的 AI）；实操 40 题（题干 + 官方评分细则 + 代码骨架填空判分 + 图文教程逐段讲解，可导出填好的 ipynb，列表同样支持混排） |
| 速查 | 56 条代码速记（技术点 / 关键代码 / 记忆口诀，可搜索可复制）、本地题库答案分布统计、14 条高频易错点、实操交付清单 |
| 模拟考 | 理论：40 判断 + 140 单选 + 10 多选 = 190 题 / 90 分钟，随机组卷、答题卡、交卷出章节正确率与错题回看；实操：按抽考规则随机抽 6 题 / 120 分钟，填空判分折算成绩 |

## 快速开始

```bash
npm install
npm run dev          # http://127.0.0.1:5273
```

打包成静态站点：

```bash
npm run build        # 产物在 dist/
npm run preview      # 本地预览打包结果，http://127.0.0.1:4173
```

`dist/` 是纯静态文件，可以直接丢到 GitHub Pages / 任意 http 服务器（因为用到 ES module，用 `file://` 直接打开会被浏览器拦，需要一个静态服务器）。

## 目录结构

```
scripts/                  数据流水线（Python，只在需要更新题目时跑）
  fetch_pages.py          抓取 ai-trainer.nccloudservice.com 的 40 道实操题页面
  build_theory.py         由题库原始 JSON 生成 src/data/theory.json
  build_practical.py      解析实操题页面，反推代码填空的标准答案
  build_cheatsheet.py     生成速记表 / 应试统计 / 易错点
  build_outline.py        由《认定要素细目表》生成考纲
  source/                 原始资料（细目表文本、题库 JSON、速记表快照、实操题 HTML）
src/
  data/*.json             生成好的数据，前端直接 import
  pages/                  Overview / Drill / Cheat / Mock
  components/             QuestionCard、TaskDetail、UI 基础件
```

更新题目（题库或站点有变动时）：

```bash
npm run fetch        # 重新抓实操题页面（1.2.x / 3.1.x / 4.x 没有代码页，404 正常）
npm run data         # 重新生成全部 JSON
```

## 判分说明

- **理论题**：判断题、单选题点完立即判对错；多选题需要点「提交」，错选漏选都算错。判分完全按题库答案。
- **实操填空**：只比对代码写法（忽略空格、引号风格、行尾注释），**不执行代码**。真实考试的评分看的是运行结果截图和 ipynb，所以填完一定要在 Jupyter 里跑一遍。
- **实操模拟**：按「填对的空数 / 总空数」折算到该题配分，是练习用的近似分，不是官方评分。
- 实操卷面按官方方案理解为：业务分析（1.1 / 1.2）抽 1 题 25 分、数据处理规范制定 15 分、算法测试 20 分、智能系统监控和优化 15 分、人机交互流程设计 20 分、培训与指导（4.1 / 4.2）抽 1 题 5 分，合计 100 分 120 分钟。若官方后续调整，改 `src/pages/Mock.tsx` 里的 `buildPracticalPaper` 即可。

## 数据来源与版权

- 考试方案、认定要素细目表、理论知识复习题（900 道）、操作技能复习题（40 道）：上海交通大学终身教育学院《人工智能训练师（三级）指导手册》与竞赛方案，发布页 <https://gjzs.sjtu.edu.cn/skill>。
- 实操题题干、评分细则、图文教程：<https://ai-trainer.nccloudservice.com/>。
- 理论题的逐题解析整理自公开的复习题详解（华是学院），题面与官方指导手册一致。
- 本站只做整理与呈现，题目和解析的版权归原机构所有，**仅供个人备考使用**，不要用于商业用途或再分发。
- 站内的「高频易错点」和难度/路线判断是编者经验总结，不是官方口径；题库答案分布统计是对这 900 道题的真实统计，不代表考场分布。

## 已知限制

- 考场随机组卷，原题命中率不可预期——刷题要记考点，别背答案位置。
- 3.1.x（Excel）和 4.x（培训/指导）不是代码题，站内只提供题干、评分细则和参考做法，没法自动判分。
- 实操题的评分细则里个别细则文案在原站点是表格合并单元格，抓下来可能出现同一句话重复，以官方手册为准。
